# Code of Conduct

## Our pledge

We want CommCoach AI to be a welcoming, harassment-free project for everyone, regardless of experience level, background, or identity. As contributors and maintainers, we pledge to make participation in this project — through issues, pull requests, discussions, or any other project space — a respectful and constructive experience for all.

## Our standards

**Examples of behavior that helps this project thrive:**

- Being respectful of differing viewpoints and experience levels — especially since this is a capstone/learning project where people are at different stages of their engineering journey
- Giving and gracefully accepting constructive feedback on code and ideas
- Focusing critique on the work, not the person
- Being patient with newcomers asking setup or "how does this work" questions — that's what the documentation effort is for
- Crediting others' ideas and contributions accurately

**Examples of unacceptable behavior:**

- Harassment, insulting or derogatory comments, and personal or political attacks
- Publishing others' private information without explicit permission
- Trolling, deliberately derailing discussions, or sustained disruption of issues/PRs/discussions
- Any conduct that would reasonably be considered inappropriate in a professional setting

## Scope

This Code of Conduct applies within all project spaces (GitHub issues, pull requests, discussions, and any associated chat channels) and also applies when an individual is representing the project in public spaces — for example, posting about the project on social media or acting as a project representative at an event.

## Enforcement

Maintainers are responsible for clarifying and enforcing these standards, and have the right to remove, edit, or reject comments, commits, code, issues, and other contributions that don't align with this Code of Conduct, and to temporarily or permanently ban any contributor for behavior they deem inappropriate, threatening, or harmful.

Consequences generally follow an escalating path depending on severity:

1. **Correction** — a private, written warning explaining the issue.
2. **Warning** — a formal warning with consequences for continued behavior, potentially including a temporary interaction ban.
3. **Temporary ban** — a temporary ban from any interaction with the project.
4. **Permanent ban** — a permanent ban from any public interaction with the project.
